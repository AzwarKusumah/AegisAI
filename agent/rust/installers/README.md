# Native Messaging Host Installation

Release downloads contain the prebuilt Rust executable and local Python inspection engine. No Rust toolchain is required on endpoint machines. Python 3.11+ is required at runtime.

## Windows GUI installer

1. Download and extract aegisai-agent-windows-x86_64.zip.
2. Install the AegisAI Chromium extension as an unpacked extension in Edge or Chrome and copy its Extension ID.
3. Open PowerShell in the extracted package directory and launch:

       powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\install-windows-gui.ps1

4. Select Edge or Chrome, enter the extension ID, HTTPS API origin, and a one-time pairing code generated by Dashboard > Devices.
5. The installer registers the per-user Native Messaging host, creates a Python virtual environment, installs document parsers, and enrolls the endpoint. Use an HTTPS API URL for remote connections; HTTP is allowed only for localhost when the endpoint connects through an SSH tunnel.
6. Restart the browser.

The installer runs as the signed-in user and does not require Administrator rights for the per-user Native Messaging registration. The script is not currently code-signed; inspect package checksums and run it only when the package source is trusted.

For local-only testing, select the local-only checkbox and leave the dashboard pairing fields unused.

## Windows command-line installer

    .\install-windows.ps1 -Browser edge -ExtensionId YOUR_EXTENSION_ID -PythonPath "C:\Path\To\python.exe"

To enroll using a one-time dashboard code:

    .\install-windows.ps1 -Browser edge -ExtensionId YOUR_EXTENSION_ID -PythonPath "python" -ControlPlaneUrl https://api.example.com -PairingCode ONE_TIME_CODE

For Chrome, use -Browser chrome. Firefox uses its fixed add-on ID aegisai@example.invalid and does not require a Chromium Extension ID.

## Linux and macOS

1. Download and extract the archive matching your OS and CPU architecture.
2. Install the AegisAI extension in Chrome/Chromium/Brave/Edge or Firefox.
3. Run the bundled installer:

       ./install-unix.sh --browser chrome --extension-id YOUR_EXTENSION_ID
       ./install-unix.sh --browser firefox

The Unix installer can be supplied the Control Plane URL and a previously enrolled agent token for legacy setups. The guided per-device pairing flow is being extended to Unix installers.

## Package contents and runtime requirements

- Native Rust agent built for the package OS/architecture.
- Python detection-engine source.
- Browser-specific Native Messaging installer and setup instructions.
- Python 3.11+ required at endpoint runtime; the installer creates an isolated venv and installs PDF/DOCX/XLSX dependencies.
- No Rust compiler is required on endpoint machines.
- Raw selected files are inspected locally; only event metadata and finding categories are sent to the Control Plane.

## Runtime configuration

Per-user configuration:
- Windows: %APPDATA%\AegisAI\config.json
- Linux: $XDG_CONFIG_HOME/AegisAI/config.json or ~/.config/AegisAI/config.json
- macOS: ~/Library/Application Support/AegisAI/config.json

Do not share this file; it contains the endpoint's agent token.

## Current limitations

The extension shows an in-page informational alert after local inspection. It does not reliably cancel provider uploads, inspect clipboard content, or provide network-level enforcement. This release is not production DLP enforcement.
